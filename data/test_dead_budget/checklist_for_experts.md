# Dead Budget 테스트 — 전공자 청취 체크리스트

> Suno에 전공 용어를 넣어 생성한 10곡. 각 곡에서 해당 기법이 실제로 들리는지 판정해주세요.
> 판정: ◯ 들린다 / △ 애매하다 / ✕ 안 들린다

---

## DB01 — Fugue (푸가)

- [ ] 하나의 주제(subject)가 명확히 제시되는가?
- [ ] 주제가 다른 성부에서 순차적으로 모방 진입(answer)하는가?
- [ ] 3성부 이상의 독립적 선율이 동시에 진행되는가?
- [ ] 스트레토(주제가 겹쳐 들어오는 구간)가 있는가?
- [ ] 에피소드(주제 없이 자유롭게 전개되는 구간)가 있는가?
- **총평**: 푸가인가, 아니면 그냥 바로크풍 합주인가?

## DB02 — Sonata Form (소나타 형식)

- [ ] 제1주제와 제2주제가 성격이 다른가? (대비 존재)
- [ ] 제시부에서 조성 이동이 느껴지는가? (C장조 → G장조)
- [ ] 발전부에서 주제의 단편화/변형이 들리는가?
- [ ] 발전부에서 단조 전조가 느껴지는가?
- [ ] 재현부에서 제1주제가 원조로 돌아오는가?
- **총평**: 소나타 형식의 3부 구조가 체감되는가?

## DB03 — Passaggio / Appoggio / Bel Canto

- [ ] 흉성(chest voice)에서 두성(head voice)으로의 전환이 매끄러운가?
- [ ] 전환 지점(E4~A4 부근)에서 음색 끊김 없이 연결되는가?
- [ ] 호흡 지지(appoggio)가 느껴지는 안정적 발성인가?
- [ ] 키아로스쿠로(밝음+어둠 공존) 음색이 있는가?
- [ ] 벨칸토적 레가토 라인이 유지되는가?
- **총평**: 성악 전공자가 듣기에 "제대로 된 벨칸토"인가?

## DB04 — Neapolitan 6th / Augmented 6th (변화화음)

- [ ] bII6(나폴리 6화음, Db 장조 울림)가 들리는가?
- [ ] 나폴리 6화음 → 딸림화음(G)으로의 해결이 있는가?
- [ ] 증6화음의 독특한 긴장감(반음계적 확장)이 들리는가?
- [ ] 최종 카덴스에서 극적 해결감이 있는가?
- **총평**: 화성학적으로 변화화음이 실제로 사용되었는가?

## DB05 — Contrary Motion / Voice Leading (반진행/성부진행)

- [ ] 바이올린(상성)과 첼로(하성)가 반대 방향으로 움직이는가?
- [ ] 각 성부가 순차 진행(stepwise)으로 움직이는가?
- [ ] 4성부가 독립적으로 진행하는가? (블록 화음이 아닌)
- [ ] 불협화음의 적절한 예비-해결이 있는가?
- [ ] 내성(비올라, 바이올린 II)이 보조적 진행(사위진행 등)을 하는가?
- **총평**: 대위법적 성부 진행 규칙이 지켜지는가?

## DB06 — Motivic Development (동기 발전)

- [ ] 4음 동기가 처음에 명확히 제시되는가?
- [ ] 확대(augmentation): 동기가 느린 속도로 반복되는가?
- [ ] 축소(diminution): 동기가 빠른 속도로 반복되는가?
- [ ] 전위(inversion): 동기가 음정 방향 뒤집혀 나오는가?
- [ ] 역행(retrograde): 동기가 거꾸로 연주되는가?
- [ ] 동기가 다른 악기로 이동하는가?
- **총평**: 체계적 동기 발전인가, 단순 반복인가?

## DB07 — Col Legno / Sul Ponticello / Sul Tasto / Con Sordino (현악 확장주법)

- [ ] 콜 레뇨(활대 나무 부분으로 두드리는 소리)가 들리는가?
- [ ] 술 폰티첼로(브릿지 근처 연주, 금속적 배음)가 들리는가?
- [ ] 술 타스토(지판 위 연주, 부드럽고 확산된 음색)가 들리는가?
- [ ] 콘 소르디노(약음기 사용, 음량 억제)가 들리는가?
- [ ] 각 주법이 구간별로 구분되어 등장하는가?
- **총평**: 현악 확장주법이 실제로 구현되었는가, 일반 현악 합주인가?

## DB08 — Coloratura / Cadenza (콜로라투라/카덴차)

- [ ] 빠른 멜리스마 패시지(한 음절에 여러 음)가 있는가?
- [ ] 2옥타브에 걸친 넓은 음역 이동이 있는가?
- [ ] 트릴, 턴 등 장식음이 들리는가?
- [ ] 카덴차(반주 없이 독창자만 자유롭게 노래하는 구간)가 있는가?
- [ ] 기교적 난이도가 느껴지는가?
- **총평**: 콜로라투라 소프라노의 기교가 실현되었는가?

## DB09 — Ritardando / Fermata / Sforzando (리타르단도/페르마타/스포르찬도)

- [ ] 클라이맥스 전에 점진적 감속(ritardando)이 들리는가?
- [ ] 한 화음이 길게 지속되며 멈추는 느낌(fermata)이 있는가?
- [ ] 페르마타 후 짧은 정적(silence)이 있는가?
- [ ] 해결 지점에서 갑작스러운 강악센트(sforzando)가 있는가?
- [ ] pp ↔ ff 다이나믹 대비가 명확한가?
- **총평**: 템포/다이나믹 지시가 실제로 반영되었는가?

## DB10 — Sprechgesang / Tessitura (슈프레히게장/테시투라)

- [ ] 절 부분에서 말하듯 노래하는 전달(sprechgesang)이 들리는가?
- [ ] 노래와 말 사이의 중간 지대가 느껴지는가?
- [ ] 후렴에서 완전한 성악적 가창으로 전환되는가?
- [ ] 주 음역대(A3~E5)가 대체로 지켜지는가?
- [ ] 절 → 후렴 전환 시 발성 방식의 차이가 명확한가?
- **총평**: 슈프레히게장이 실현되었는가, 그냥 일반 팝 보컬인가?
