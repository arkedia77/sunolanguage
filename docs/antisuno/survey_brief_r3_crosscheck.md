# antisuno · R3 브리프 — 독립 교차검증 라운드 (검증자: `agy`)

**왜 R3인가**: Phase 0·R2는 **`codex exec` 단독**이었다. 08-31에 나는 그 한계의 원인을 「gemini 미인증」으로 적었는데 **09-04 정정** — 이 머신의 구글 CLI는 `agy`(antigravity-cli)이고 인증은 살아 있었다. 검증자는 있었고 내가 안 불렀다.

## ★블라인드 규칙 (이 라운드의 핵심)
**우리 값을 검증자에게 보여주지 않는다.** 「이 숫자가 맞습니까」라고 물으면 확증편향이 돌아온다.
⇒ **같은 질문을 백지에서 다시 회수**시키고, **회수가 끝난 뒤에** 우리 값과 대조한다.

## 절대 규칙 (Phase 0 브리프 §절대규칙 승계)
1. **출처 없는 값은 `null`.** 추정·기억·「일반적으로」 금지.
2. 각 값에 **URL 실물**과 **등급**을 붙인다: `E1`=벤더 공식 문서/논문 · `E2`=벤더 블로그·릴리스노트 · `E3`=1차 소스 인용한 3자 문서 · `E4`=커뮤니티 관측(Reddit·블로그).
3. ⛔**E급(문서)과 M급(우리 실측)을 절대 섞지 않는다.** 이 라운드 산출은 전건 E급이다.
4. 404·접근불가는 그렇게 적는다. 「못 찾음」과 「없음」을 구분한다.

## 회수 문항 (엔진별)
1. **프롬프트/스타일 입력 문자 상한** — 정확한 숫자와 그것이 적힌 문서 URL. (대상: Suno · Udio · ElevenLabs Music · MiniMax Music · Mureka · Stable Audio · ACE-Step · Lyria)
2. **한국어 지원** — 공식 문서가 **음악 생성**(speech·TTS 문서 아님)에서 한국어를 명시하는가. 명시 언어 목록 그대로.
3. **가사 채널의 대괄호/중괄호/소괄호 문법** — 공식이 정의한 토큰과 그 의미. 특히 **길이·시간을 태그에 넣는 문법**이 있는가.
4. ★**「구조·지시 태그는 가창되지 않는다」를 공식 문서가 보증하는가** — 보증 문장이 있으면 원문 인용. 없으면 `null`. *(이 문항은 부정 주장을 깨려는 것이다. 하나라도 찾으면 그게 이 라운드 최대 소득이다.)*
5. **seed / 재현성 파라미터**의 유무와 이름.
6. **가중 프롬프트·네거티브 프롬프트·구간 편집(inpaint)·BPM/키 독립 파라미터**의 유무와 이름.

## 출력 형식
클러스터당 JSON 1덩이. 스키마는 `docs/antisuno/survey_brief_v0.md` §출력형식과 동일(엔진별 객체 + `sources[]`).
산출 위치: `data/antisuno/survey3/raw_{cluster}.txt` → `parsed_{cluster}.json`

## 대조 절차 (회수 후 내가 한다)
1. R3 값 ↔ Phase 0/R2 값 **칸별 대조표** 작성 — 일치 / 불일치 / R3만 / R0만
2. **불일치는 지우지 않는다.** 어느 쪽이 더 높은 등급의 출처를 댔는지로만 판정한다.
3. 대장 칸 이동은 **E급끼리는 안 한다**(v1.4 §4) — R3는 신뢰도를 올릴 뿐, M급 실측을 대신하지 않는다.
