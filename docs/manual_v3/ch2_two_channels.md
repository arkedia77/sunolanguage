# 2장: 두 채널 시스템 — SP 산문 vs 가사 브래킷

> Suno는 하나의 음악을 두 가지 언어로 묘사한다: SP의 산문체 분석과 가사 안의 [] 브래킷 지시. 각 채널은 고유한 역할이 있다.

## 2.1 채널 개요

Suno가 음악을 재분석하면 두 가지 텍스트를 출력한다:

- **Style Prompt (SP)**: 음악의 전체 구조를 서술하는 산문체 텍스트. 장르, 악기 편성, 주법, 프로덕션, 보컬 특성, 템포/조성을 포괄한다.
- **가사**: 가사 텍스트 안에 [] 브래킷과 () 괄호를 삽입하여 섹션 구분과 연주 지시를 전달한다.

이 두 채널은 동일한 음악을 다른 관점에서 묘사한다. SP는 "이 음악은 무엇인가"를, 가사 브래킷은 "이 음악이 어떤 순서로 진행되는가"를 전달한다.

### 핵심 규칙

1. **장르와 템포는 SP에서만 선언된다.** 브래킷에서 장르를 지정하는 경우는 0건.
2. **섹션 구분은 브래킷에서만 일어난다.** `[Intro]`, `[Verse 1]`, `[Chorus]` 등의 구조 지시는 SP에 나타나지 않는다.
3. **악기와 드럼은 양쪽 채널에 동등하게 분포한다.** SP에서 전체 편성을 기술하고, 브래킷에서 특정 지점의 진입/퇴장을 지시한다.
4. **믹싱 관련 어휘는 SP에만 존재한다.** reverb, compression, EQ 같은 프로덕션 용어는 브래킷에서 거의 나타나지 않는다.

## 2.3 양쪽 채널에 공존하는 표현

97개 표현이 SP와 브래킷 양쪽에 출현한다. 이들은 Suno가 두 채널에서 공통으로 사용하는 핵심 어휘다.

| 표현 | SP 빈도 | 브래킷 빈도 | 역할 차이 |
|------|--------:|----------:|----------|
| electric bass | 345 | 348 | SP: 주법 묘사 / 브래킷: 진입 시점 |
| electric guitar | 279 | 268 | SP: 톤/이펙트 / 브래킷: 진입·리프 |
| kick drum, drums | 75 | 57 | SP: 패턴 묘사 / 브래킷: 진입 |
| reverb | 59 | 18 | SP: 프로덕션 / 브래킷: 이펙트 큐 |
| distorted | 37 | 40 | 양쪽에서 동등하게 사용 |
| vinyl crackle | 8 | 7 | 양쪽에서 동등하게 사용 |

SP에서는 악기의 **특성**(톤, 주법, 효과)을 묘사하고, 브래킷에서는 악기의 **시점**(진입, 퇴장, 변화)을 지시하는 패턴이 일관적이다.

## 2.5 () 괄호 시스템

가사 텍스트 안의 () 괄호는 [] 브래킷과 다른 역할을 한다.

### 괄호의 역할: 보컬 행위 지시

Leo의 실청취 검증 결과, () 안의 지시는 Suno가 실제로 반응하는 보컬 퍼포먼스 디렉션이다. 4/4 테스트 전부 유효:
- `(hums softly)` → 허밍 생성
- `(melismatic runs)` → 멜리스마 생성
- `(trills/scales)` → 트릴/스케일 보컬
- `(spoken)` → 스포큰 워드

DB 385행에서 발견된 () 사용 패턴:

| 유형 | 예시 | 빈도 |
|------|------|------|
| 감탄사/허밍 | (Hmm-mm), (Ooh-ooh), (Humming) | 28 |
| 응원/추임새 | (Woo-hoo!), (Yeah), (Woo!) | 14 |
| 한국어 | (우후), (음-) | 6 |
| 악기 모방 | (808, 808, 808, 808), (sax-o-vol) | 6 |

### [] vs () 차이

| 구분 | [] 브래킷 | () 괄호 |
|------|----------|---------|
| 위치 | 가사 줄 사이 (독립 행) | 가사 줄 안 (인라인) |
| 역할 | 섹션 구분, 악기 큐, 보컬 큐 | 보컬 행위 디렉션, 감탄사 |
| 대상 | 편곡/구조 | 가수의 퍼포먼스 |
| 검증 | 구조 수준 확인 | 4/4 실청취 유효 |

## 2.6 브래킷 시퀀스 문법 — Suno가 가사를 구성하는 순서

445곡의 가사에서 [] 브래킷의 출현 순서를 분석하면, Suno가 곡 구조를 구축하는 정형화된 문법이 드러난다.

### 기본 통계

| 항목 | 값 |
|------|-----|
| 곡당 평균 브래킷 수 | 8.2개 |
| 중앙값 | 7개 |
| 범위 | 2~24개 |

### 포지션별 브래킷 유형 분포

각 곡에서 N번째 브래킷이 어떤 유형인지 분류한 결과:

| 위치 | 1위 | 2위 | 3위 |
|------|-----|-----|-----|
| #1 | **SECTION 100%** | — | — |
| #2 | **INSTRUMENT 72%** | SECTION 19% | TRANSITION 7% |
| #3 | **SECTION 77%** | INSTRUMENT 10% | TRANSITION 9% |
| #4 | **VOCAL 71%** | SECTION 11% | INSTRUMENT 11% |
| #5 | TRANSITION 43% | SECTION 25% | INSTRUMENT 23% |
| #6 | SECTION 34% | TRANSITION 32% | INSTRUMENT 24% |
| #7+ | 혼합 | — | — |

**핵심 패턴**: 첫 4개 브래킷은 거의 고정이다:
1. `[Intro]` (섹션)
2. `[fingerpicked acoustic guitar]` 등 (악기 진입)
3. `[Verse 1]` (섹션)
4. `[breathy male vocals]` 등 (보컬 진입)

### 지배적 시퀀스 (Top 5)

| 시퀀스 | 빈도 |
|--------|------|
| SECTION → INSTRUMENT → SECTION → VOCAL → TRANSITION | 29 |
| SECTION → INSTRUMENT → SECTION → VOCAL | 19 |
| SECTION → INSTRUMENT → SECTION → VOCAL → TRANSITION → SECTION | 13 |
| SECTION → INSTRUMENT → SECTION → VOCAL → SECTION | 11 |
| SECTION → INSTRUMENT → SECTION → VOCAL → TRANSITION → SECTION → TRANSITION | 10 |

모든 상위 패턴이 **SECTION → INSTRUMENT → SECTION → VOCAL**로 시작한다. 이 4단계는 Suno 가사의 "골격"이다.

### 섹션 마커 직후에 오는 것

| 유형 | 비율 | 해석 |
|------|------|------|
| INSTRUMENT | 40.5% | 섹션 전환 시 악기가 진입/변화 |
| VOCAL | 31.6% | 섹션에서 보컬 큐 선언 |
| TRANSITION | 15.2% | 악기 enters/swells |
| SECTION | 12.7% | 연속 섹션 마커 |

### `enters` 패턴의 위치

- 악기 진입(`enters`)은 곡 전체의 **중간 지점**(상대 위치 0.53~0.56)에 집중
- 앞부분에서 최소 편성 → 중간에서 악기 추가 → 후반에서 풀 밴드: Suno의 빌드업 전략

### 가사 작성 규칙: 브래킷 문법 따라하기

Suno의 네이티브 가사 브래킷 순서:

```
[Intro]                           ← #1: 반드시 섹션으로 시작
[fingerpicked acoustic guitar]    ← #2: 오프닝 악기 진입
[Verse 1]                         ← #3: 첫 섹션
[breathy male vocals]             ← #4: 보컬 큐
(가사...)
[bass guitar enters]              ← #5: 추가 악기 진입 (곡 중반)
[Chorus]                          ← #6: 다음 섹션
(가사...)
```

## 2.7 () 괄호의 사용 빈도와 위치

### 기본 통계

| 항목 | 값 |
|------|-----|
| () 사용 곡 | 76/445 (**17.1%**) |
| 총 () 출현 | 133회 |
| 곡당 평균 (사용 곡 기준) | 1.8개 |

**대부분의 곡(83%)은 ()를 사용하지 않는다.** ()는 선택적 장식이지, 필수 구조 요소가 아니다.

### () 내용 분류

| 카테고리 | 비율 | 대표 예시 |
|----------|------|-----------|
| 감탄사/허밍 | 62.4% | (Hmm-mm), (Ooh-ooh), (Woo-hoo!) |
| 기타 | 22.6% | (L-A-A-A), (Ha-ah-ah-ah) |
| 한국어 | 10.5% | (우후), (음-) |
| 악기 모방 | 4.5% | (808, 808, 808, 808), (sax-o-vol) |

### () 출현 위치

- 평균 상대 위치: **0.36** (곡 앞쪽 1/3)
- 중앙값: **0.18** (곡 초반에 집중)

()는 곡의 **앞부분**에 집중된다. Intro나 Verse 1 근처에서 감탄사/허밍이 가장 많이 등장하며, 곡이 진행될수록 () 사용이 줄어든다.

## 2.8 SP 작성을 위한 시사점

1. **장르와 템포는 반드시 SP에 넣어라** — 브래킷에서는 인식되지 않는다.
2. **섹션 구분은 가사 브래킷으로** — `[Intro]`, `[Verse 1]` 등은 가사에서만 작동한다.
3. **악기 진입 시점은 `[X enters]` 형식으로** — 브래킷에서 시간적 진행을 제어한다.
4. **보컬 행위 디렉션은 () 괄호로** — `(hums softly)`, `(spoken)` 등은 가사 안에 인라인으로.
5. **SP의 악기 묘사 = 전체적 특성, 브래킷의 악기 묘사 = 시간적 진입** — 역할을 구분하라.
6. **`breathy`는 Suno의 기본 보컬 수식어** — 보컬 큐에서 가장 자주 등장(86회).
7. **브래킷 문법을 따르라** — 첫 4개 브래킷: [Intro] → [악기] → [Verse 1] → [보컬 큐]. 이 순서를 깨면 Suno의 네이티브 패턴에서 벗어난다 (§2.6).
8. **() 괄호는 선택적 장식** — 83%의 곡이 ()를 사용하지 않는다. 허밍/감탄사가 필요할 때만 곡 앞부분에 배치 (§2.7).
9. **악기 enters는 곡 중반에** — `[bass enters]`, `[synth pad swell]` 같은 진입 큐를 곡의 40~60% 지점에 배치하면 Suno의 빌드업 전략을 활용할 수 있다.

> **생성 측 검증 (N시리즈 140곡, → 6장 6.1)**: 채널 분리(규칙 5)를 어기면 곡이 실제로 망가진다. 우리 생성 파이프라인 초기 배치(N003~N005)에서 SP 산문 채널 문구(`Layered leads, maximum energy`)가 가창 가사 슬롯에 새어든 곡이 4건 나왔고, 이들은 전체 140곡 중 coherence 최저대(0.35~0.38)로 떨어졌다(영어 지시문이 한국어 가사와 토큰 비공유). N006에 산문-디렉티브 차단 게이트를 넣자 누출은 0으로 멎었다. **채널 경계는 작성 규칙일 뿐 아니라 생성 품질의 측정 가능한 분기선이다.**
