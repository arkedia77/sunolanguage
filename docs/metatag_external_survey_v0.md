## 1. ★대조축의 정의 (이걸 틀리면 아래 숫자가 전부 오독된다)

코퍼스 브라켓의 출처는 `parse_slot_entities_v3.py:887` 루프 —
`merged_4values.json` → `song["suno_reanalysis"][*]["lyrics"]`, 즉 **Suno가 스스로 출력한 브라켓**이다.

| 본 대조가 답하는 질문 | 답하지 **않는** 질문 |
|---|---|
| Suno 자신이 그 표기를 뱉은 적이 있는가 | 그 태그를 **입력하면 반응하는가** |

**출력어휘 ≠ 입력제어.** 따라서 `ABSENT` = 「Suno가 안 뱉었다」이지 **「안 먹힌다」가 아니다**.

### 검산 (거짓 0 방지 — 통과)
- 양성대조: `[Intro]` 548곡 · `[Chorus]` 320곡 · `[Instrumental]` 137곡 → 질의 철자 정상
- 음성대조: 무의미 문자열 2건 = 0 → 매칭 헐거움 없음
- 부분일치는 **단어경계** 강제(안 하면 `[no]`가 "pia**no**"에, `[end]`가 "b**end**"에 걸림)
- 독립 교차검증: `[Male Vocal]` exact **0곡** = `duet_bracket_grammar_v1.md`가 다른 방법(GLOB 대소문자)으로 낸 0건과 일치

## 3. 진짜 소득 — 반증 목록 (코퍼스가 원리상 못 만드는 축)

우리 코퍼스는 **Suno가 뱉은 것만** 본다. 「입력했는데 무시당했다」는 관측이 구조적으로 안 잡힌다.
`gh_stayen`(자체 400회 생성 교차시험 주장)이 그 축의 데이터를 유일하게 갖고 있다:

| 태그 | 외부 주장 |
|---|---|
| `[autotune: ...]` `[loop: ...]` | 미지원 |
| `[filter:]` `[mix:]` `[master:]` `[pan:]` | 무효(inefficient) |
| `[style: none]` | 무효 |
| `[end]` | 빈번 무시 — 인용: "`[5 second fade out][end]` 조차 정지 못 시킴" |
| `[personae:]` | 사용자 시도일 뿐, 공식 미지원 |

★**미검증 주장이다**(우리가 재현한 것 아님). 다만 **파일럿 후보로서는 값이 있다** — 데드존 3계층(`ch5_absence.md`)의 기존 사례와 같은 형태이고, 화자 명찰 데드존과 달리 아직 우리 실측이 없다.

## 4. ★역방향 격차 — 외부가 못 본 것 (소득만 세면 절반만 보는 것)

Suno가 자주 뱉는데 **외부 288개 어느 목록에도 없는** 표기:

| 곡수 | 표기 | 비고 |
|---|---|---|
| 66 / 64 | `Section A` / `Section B` | ★외부 전무 |
| 39 | `Main Section` | ★외부 전무 |
| 31 | `Main Theme` | ★외부 전무 |
| 19 / 19 | `A Section` / `B Section` | 같은 계열 이표기 |
| 75 / 33 | `breathy male vocals` / `breathy female vocals` | 서술형 |
| 35 | `fingerpicked acoustic guitar` | 서술형 |

**Suno의 자체 구조어휘는 Verse/Chorus 축이 아니라 Section A/B·Main 축을 별도로 갖는다.**
외부 288개는 전부 팝송 폼(Verse/Chorus/Bridge)만 다루고 이 축을 못 봤다. 리버스만이 가진 자산.

### 부수 발견 — 번호 규약 비대칭
| 표기 | 곡수 |
|---|---|
| `Verse 1` | **458** |
| `Verse 2` | 114 |
| `Verse` (맨) | **1** |
| `Chorus` (맨) | **320** |

Suno는 **verse에는 번호를 붙이고 chorus에는 안 붙인다**. 외부 목록은 공식문서 포함 전부 맨 `[Verse]`를 가르치는데, 그 형태는 Suno 자신이 사실상 안 쓴다(1곡).

## 5. ABSENT 95건을 「반증 95건」으로 읽지 말 것

ABSENT는 두 종류가 섞여 있고 **성격이 다르다**:

- **(a) 섹션라벨형** (`[Post-Chorus]` 계열 등) — Suno 출력에 안 나온 게 유의미한 의심
- **(b) 지시형** (`[Crowd yells]` `[Whisper]` `[Fade Out]` `[Primal Scream]`) — **애초에 서술 브라켓에 나올 이유가 없다**. 본 코퍼스로는 **판정 불가**이지 반증 아님

특히 유튜브 ABSENT 6건 중 5건이 `40Pg2iNnWR4`(설명란에 "Meta Tags Used:" + 태그별 데모 챕터를 둔, 유튜브 중 가장 시험처럼 보이는 출처)의 것인데 전부 **(b) 지시형**이다.
→ 「가장 믿을 만해 보이는 유튜브 출처가 전부 틀렸다」로 읽으면 **오독**. 우리 관측축 밖일 뿐이다.
