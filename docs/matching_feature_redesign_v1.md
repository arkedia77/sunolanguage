# 매칭 피처 재설계안 v1 (1p) — TAU10 전문항 '아니오' 대응

**작성**: 2026-07-17 | **발주**: kee(LEO 판정 13:29 경유) | **게이트**: 본안 검토 통과 시에만 τ 파일럿 2호 상정
**전제**: 잔여 90곡 일괄매칭 **보류 확인**. 기존 매칭 산출(run1~15)은 '검증전' 취급.

## 1. 진단 — 왜 전 대역이 '아니오'였나 (근거: scripts/reference_matcher.py 실물)

현 매처는 **순수 텍스트 공간**: M1 임베딩(MiniLM) + M2 FTS bm25 + M3 사전카운트의 RRF 융합.
스케일·BPM·장르·악기셋 **구조 피처가 0개** — "비슷한 어휘로 서술된 SP"를 찾을 뿐,
"같은 느낌으로 들리는 곡"을 찾지 않는다. LEO 노트가 축별로 이 괴리를 정확히 짚음:

| 판정 | LEO 지적 | 매처 결함 대응 |
|---|---|---|
| TAU06 | 시타르 안 씀·스케일 다름 | 악기 존재/부재를 점수화하지 않음(어휘 빈도만) |
| TAU07 | 믹싱·이펙팅이 분위기 자체를 바꿈 | production 질감이 통합 임베딩에 희석 |
| TAU08 | 고조·모티브 강조가 다름 | 에너지 커브(시간 구조) 무표현 |
| TAU09 | '그나마 유사' | 오케스트럴 어휘 밀도가 우연히 4축 근사 = 유일 부분성공 |
| Q3 | 습관적 악기배열 과다 | 코퍼스 고빈도 기본값이 매칭을 지배(★A-046 다양성 마모 동계열) |

## 2. 재설계 — LEO 4축 사전식(lexicographic) 게이트 + 텍스트 채널 강등

**F1 스케일(하드 게이트)** — SP에서 `key of X major/minor` 정규 추출(코퍼스 652건 attested, tracks.key 병용).
모드 불일치 = 즉시 제외. 미상 곡은 미상 버킷 격리(무모드 매칭 금지).

**F2 템포(하드 밴드)** — BPM ±10%(3밴드 폴백). ★클래식 루바토류('템포가 없음')는 무템포 클래스로 분리, 무템포끼리만 매칭.

**F3 장르(소프트 상위 가중)** — genre_aliases 정규화 + 사운드앵커 우선(3070 실증: Suno 장르명 드리프트).

**F4 악기 배열(소프트, IDF 가중 자카드)** — 곡별 악기셋(lexical_index slot=instrument).
★코퍼스 IDF: 습관 악기(electric bass 등 고빈도 기본값) 가중 하향, 특징 악기(시타르 등 희소) 가중 상향 + **부재 페널티**.
'습관적 악기배열' 지적 직격 대응 — A-046 diversity-erosion-prevention-v0 탐지축 참조.

**F5 보조 소프트 2채널(귀 노트 반영)** — ⓐ에너지 커브 프록시: dynamics 슬롯 시퀀스(build/swell/crescendo/drop/breakdown)의 순서 유사도 ⓑ믹싱 질감: production 슬롯 독립 채널(희석 해제).

**기존 M1/M2/M3** → F1~F4 통과 후보 내 순위결정(타이브레이커)로 강등.

**한계 정직 명기**: 감정 고조·믹싱 질감은 텍스트 프록시로 불완전 — 중기 정공은 leomusic3 기계귀(CLAP)와의
하이브리드(encore 3채널 합의 경로). 본안은 텍스트층에서 도달 가능한 최대치.

## 3. 재검증 방법 (파일럿 2호 상정 게이트)

1. **소급 재현 — TAU10 판정문 = 골드셋**: 신 파이프라인이 ①TAU06을 F1(스케일)·F4(시타르 부재 페널티)로 배제
   ②TAU07을 F5ⓑ 저점 강등 ③TAU08을 F5ⓐ 저점 강등 ④TAU09를 최상위 유지 — 4건 전건 정합 시에만 다음 단계.
2. **파일럿 2호**: 신규 10곡 동일 층화, ★성공 기준 사전 명시(Y율 ≥5/10 + 고스코어 대역(Q2 상당) Y 필수 — Q2 재붕괴 시 즉시 중단).
3. **실패 시**: 텍스트 단독 매칭 한계 인정 → 기계귀 하이브리드로 에스컬레이션(leomusic3 협의 발주).
