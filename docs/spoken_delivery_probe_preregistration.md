## 3. 지표 — 값 보기 전 고정 (3종)

프레임 10ms, F0 추정 = 자기상관(YIN 계열) 자체 구현, 탐색역 70~700Hz.

| # | 지표 | 정의 | 방향(선험) |
|---|---|---|---|
| ⓐ | **sustain ratio** | 유성 프레임 중, F0가 **±0.5 반음 이내로 ≥120ms 연속** 유지되는 구간에 속한 프레임 비율 | 노래 **높음** / 말 **낮음** |
| ⓑ | **\|Δ반음\| 중앙값** | 인접 유성 프레임 간 반음 변화 절대값의 중앙값 | 노래 **낮음** / 말 **높음** |
| ⓒ | **voiced ratio** | 전체 프레임 중 유성 프레임 비율 | 노래 **높음** / 말 **낮음**(무성자음·휴지) |

**ⓐ가 주지표**다. ⓑⓒ는 보조.

## 4. 대조군 — ★이게 없으면 아무 말도 못 한다

| 극 | 무엇 | 왜 |
|---|---|---|
| **노래 극(A)** | **같은 클립의 가창 라벨 구간** | 같은 목소리·같은 믹스·같은 분리기 → 개체차·처리차 제거(곡 내 자기대조) |
| **말 극(B)** | macOS `say` ko_KR로 합성한 **동일 4문장** | 「말하기」의 기준점. ★단 **기계 말**이라 인간 낭독의 대체가 아니다 — **하한 기준으로만** 쓴다 |

## 5. 판정 규칙 — 값 보기 전 고정

각 지표에서 대상 구간의 위치를 두 극 사이로 정규화한다: `z = (x − B) / (A − B)`

- `z ≤ 0.35` → **말하기 쪽**
- `z ≥ 0.65` → **노래 쪽**
- `0.35 < z < 0.65` → ★**판정 보류**(중간을 한쪽으로 접지 않는다)

**3지표 중 2개 이상이 같은 방향**일 때만 결론을 낸다. 갈리면 **보류**.

## 6. ★기각 조건 — 먼저 통과해야 하는 게이트

**노래 극(A)와 말 극(B)이 ⓐ에서 분리되지 않으면**(|A−B| < 0.15) →
**지표가 말/노래를 구분하지 못한다는 뜻이므로 대상 구간 판정을 아예 하지 않는다.**
「분리 안 되는 자로 잰 값」을 결과라고 내놓지 않는다.

## 7. 미리 아는 한계 (값 보기 전 기재)

1. **N=2 클립 · spoken 4행.** 어떤 결과가 나와도 곡 수준 일반화 금지.
2. **htdemucs 분리 잔여물**(반주 누출·잔향)이 F0 추정을 흔든다. 절대값이 아니라 **같은 클립 내 상대 비교**로만 쓴다.
3. **TTS는 인간 낭독이 아니다.** B극이 실제 사람 말보다 단조로울 수 있고, 그러면 z가 노래 쪽으로 부풀 수 있다 → **말하기 판정에 보수적, 노래 판정에 관대**한 방향의 편향. 결론에 방향까지 적는다.
4. Bridge 대사는 **남녀 교대**라 화자가 섞인다. 행 단위로 분리해 재되, **성별 분리는 안 한다**(못 한다).
5. 이 판정은 **Suno 산출물**에 대한 것이다. 실제 커미션은 **사람이 부르는 가이드곡**이라 최종 담보가 아니다.
6. RM1은 도입 대사가 **1회 에코 반복**된다(기판정). 반복분이 구간에 섞이면 지표가 흔들릴 수 있다 — 결과에 표시한다.
