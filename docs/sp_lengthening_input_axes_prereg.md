# Suno 가 SP 를 «늘리는» 입력 조건 — 곡 단위 사전등록 (2026-10-23 20:1x · 결과 열기 전)

**왜**: ①-79 판정 — 성별어 깨짐은 입력 변수(길이·위치·장르)로 못 가렸고, 강한 축은 결과 쪽 **길이비 > 1.0**(09-13 곡 단위 27.3% vs 4.7%)뿐. ⇒ 그 길이비 > 1.0 을 **입력 쪽에서** 예측할 수 있나.
**층**: 렌더 입력 텍스트층(`sunolang.db:suno_sp_emissions` · emitted_sp 대 ordered_sp) — ⛔오디오층 아님.

## 분모 (결과 안 보고 확정)
- `suno_sp_emissions` 중 `aug_creativity` ∈ {2,3,4} 클립(대조본) — 열기 전 집계: aug2 358클립/179곡 · aug3 460/230 · aug4 400/200 · aug1 2/1(제외 · n=1) · aug0(정본) 은 제외(무수정 축).
- **곡 단위**(곡 = aug>0 클립 2개). 곡의 장르 = PG `songs.genre_group`.

## 결과 변수
- **Y** = 곡의 대조본 클립 중 **하나라도 `length_ratio` > 1.0**.

## 설명 변수 (입력 쪽만)
- **X1** = `ordered_sp` 길이(문자). 방향 가설(적어 둠 · 검정은 양측): 짧은 SP 일수록 늘린다.
- **X3** = genre_group 6종.
- **A** = aug 단계(2/3/4) — 레버이지 입력 문면이 아니다 ⇒ χ²(3×2) 로 따로 보고 X1·X3 해석 시 층화 설명.

## 검정·판정선 (1회 봉인)
- X1: Mann-Whitney U(양측) · X3: 각 장르 vs 나머지 Fisher 6회 · A: χ²(3×2) 1회 ⇒ k=8 ⇒ **유의 = p < 0.00625** · 0.00625 ≤ p < 0.05 = 「신호 후보 · 확인 아님」.
- 보조(설명·검정 아님): X1 사분위별 Y 비율.
