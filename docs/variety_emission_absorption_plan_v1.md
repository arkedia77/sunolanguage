## 0. ⛔★★ v1은 틀렸다 — 먼저 적는다

**v1의 결론**: 「우리가 쥔 칸에는 수노가 뱉은 것이 없다. ⓒ 클립 산출층 보유 **0건**.」
**v2의 결론**: ★**그 층을 우리는 «이미» 954클립 쥐고 있었다.** 제가 **칸 이름을 층으로 읽었다.**

| | |
|---|---|
| 뒤집은 근거 | sunomusic 2026-09-14 회신 — API `GET /api/clip/{uuid}`의 **`metadata.tags`** ↔ 그쪽 통의 **`렌더입력SP`**가 `.strip()` 후 **완전 동일**(대상 = I003 gid 10222 · `aug_creativity` 3 · 길이비 0.4911) |
| ★내 독립 검산 | ⒜ 통의 `발주SP_길이` == 내 설계 SP 길이 **2,000/2,000 일치** ⇒ `발주SP`가 우리 것 ⒝ `렌더입력SP` == 내 설계 SP 원문 = V0 **1000/1000 동일**, V2 14/358 · V3 6/180 · V4 26/460만 동일 ⇒ **954클립이 다르다**. 그 「동일」 수가 내 `무수정` 칸과 **정확히 일치** |
| 왜 속았나 | ★**칸 이름이 `렌더입력SP`(=「입력」)였고, Variety 0에서는 수노가 우리 SP를 «그대로» 돌려준다** ⇒ V0 1,000클립이 전부 동일하게 보였다. 나는 그걸 「우리 것이 되돌아온 칸」으로 읽었다 |

★**교훈(내 계열의 반복)**: **「없다」가 나오면 내 조회기 → 내 질의문 → 그 다음은 «내가 읽은 칸 이름»**이다. 이름이 층을 잘못 말하면 **가진 것을 못 찾으러 간다.** (그쪽도 「제 칸 이름이 오해를 만들었습니다」로 자기 몫을 먼저 적었다 — 스키마 문서에 못 박겠다고 회신.)

### 0-1. ✅ 같은 측정에서 «맞은» 것 — 가사 층은 **닫는다**
v1 §0의 실측(가사 브라켓 **추가 0 · 소실 0 · 1,080/1,080 집합 동일**)은 **정확했고**, 그쪽이 확인했다: `metadata.prompt`(=가사)는 **우리가 넣은 원문 그대로**이며 ⛔**Variety로 재작성되지 않는다. 재작성되는 것은 SP뿐이다.**
⇒ ★v1 §6에 「③의 답이 «같은 문자열»이면 실패로 적고 닫는다」고 미리 적어 뒀다. **가사 브라켓 흡수 계획은 그 조건대로 닫는다.**

### 0-2. ✅ Variety 표기 — 확정과 금지
- **확정**: UI 슬라이더는 **`0~4` 정수 단계**(기본 1). API는 `metadata.control_sliders.aug_creativity`에 **그 정수**를 싣는다. (근거=sunomusic CDP 실측 + 클립 덤프 실물)
- ⛔**금지**: **백분율 환산을 쓰지 않는다.** 「V3 = 75%」는 **근거가 없다.** LEO의 「50%·100%」는 구어로 보이며 그쪽도 **확정으로 못 준다**고 했다(그쪽이 한 것은 지시를 4→2로 집행한 것뿐).

## 3. 분석 사전등록 (★분석 «전»에 적는다)

**설계의 강점 = 대조쌍이 이미 곡 안에 있다.** 같은 곡의 primary(V0) ↔ pair(V2/V3/V4)는 **동일 발주 SP·동일 가사**다 ⇒ 시기·모델 교란이 안 섞이는 **곡 내 쌍 대조**. (⛔V2·V3·V4 **버킷끼리** 비교는 시기·라인 지시가 달라 교란이 섞인다 — 안 한다.)

- **분모** = 재작성 클립. **V3 174 · V2 344 · V4 434**.
- **1차 물음(어휘)**: 수노 재작성 SP에 **우리 발주 SP에 없던 낱말·구**가 얼마나 들어오나. 그중 **현행 사전 20,456 entries·453개념에 없는 것**이 신어 후보.
- **2차 물음(브라켓)**: 재작성 SP에 **대괄호가 나타나는가**. ⛔현재까지 **0/2,000**. 새로 1건이라도 나오면 **그게 LEO가 보신 것**일 수 있다 ⇒ **배치별로 세어 추세를 본다**(0을 0으로 숨기지 않는다).
- **귀무** = Variety 단계가 올라가도 신어 유입률이 같다.
- ⛔**판정 낱말은 검정력 80% 도달 전에는 안 쓴다.** 필요 표본은 **기저율 실측 직후 선을 먼저 등록**하고 그 다음 집계한다(수를 보고 선을 옮기지 않기 위해).
- **따로 세는 칸**(0으로 숨기면 다음에 못 본다): 한국어·프랑스어 재작성 · 구조 태그 ↔ 음향 지시 · 길이 축소/확장 방향.
