## 2. 측정 방법

### 2.1 단일 어휘집 L
L = 코퍼스 전체 관측 엔티티(`slot='instrument'`)의 정규화 고유값 집합.
정규화 = 소문자 · 앞뒤공백 제거 · 연속공백 1칸 · 하이픈→공백.

**요청층과 관측층을 같은 자로 잰다.** 두 층에 다른 자를 대면 차이가 자의 차이인지 층의 차이인지 안 갈린다.

### 2.2 곡별 두 집합
- **R**(요청) = { t ∈ L : t가 그 곡의 요청 SP **원문 텍스트**에 부분문자열로 존재 }
- **O**(관측) = { t ∈ L : t가 그 곡의 관측 엔티티로 실제 추출됨 }

### 2.3 지표 2개
| 지표 | 정의 | 읽는 법 |
|---|---|---|
| **채택율 uptake** | \|R∩O\| / \|R\| | 요청한 악기가 관측에 살아남은 비율 |
| **부가율 addition** | \|O\R\| / \|O\| | 관측 악기 중 **요청에 없던** 비율 = 순수 관측 기여분 |

### 2.4 ★대조군 (없으면 측정 안 한 것과 같음)
[[feedback_measure_before_reporting_zero]] 자기적용. **짝 섞기(permutation)** 대조군을 둔다.

- 같은 곡의 O를 **다른 곡의 요청 SP**와 대조 → `chance_uptake` / `chance_addition`
- 결정적 순열(고정 시드·순환 시프트)로 재현 가능하게 한다.

**대조군이 필요한 이유**: 악기 어휘는 흔하다. `piano`가 요청 SP에 있었다는 사실만으로는
「우리가 요청해서 나왔다」의 근거가 못 된다 — 아무 곡의 요청 SP에나 `piano`가 있을 수 있다.
**실측치와 우연치의 차이만이 신호다.**

### 2.5 교락 후보 축 (전부 세우고 통제 여부를 명기 — encore 08-04 교훈 차용)
| 축 | 통제 가능? | 처리 |
|---|---|---|
| 배치 | **부분만** (152/497만 `series` 보유) | 통제 불가분은 **불가라고 적는다**. 조용히 넘기지 않는다 |
| 인스트루멘탈 | 가능 (`is_instrumental` 152건) | 보조 분해 |
| 어휘 흔함(빈도) | 가능 | L 빈도 십분위별 분해 |
| 요청 SP 길이 | 가능 | 상관 보고 |
| L의 관측 편향 | **불가** | §4 한계에 명기 |

## 3. 사전 기각 조건 (이 값이 나오면 코어를 안 세운다)

1. **부가율 − 우연부가율 ≤ 5%p** → 관측층은 요청층의 메아리다. 코어 세울 근거 없음 → **폐기**.
2. 부가 상위 어휘가 **파서 아티팩트**(`synthesizer` 같은 상위어 자동부가 등)로 과반 설명되면 → 그 부분 **차감 후 재판정**.
3. 채택율이 우연채택율과 구별 안 되면 → 요청층·관측층 연결 자체가 안 잡힌 것이므로 **방법 실패**로 적는다(층 차이라 주장 금지).

## 4. 미리 아는 한계 (측정 후에 발견한 척 하지 않기 위해 먼저 적음)

- **L은 관측에서 뽑았다.** 따라서 요청 SP에만 있고 Suno가 한 번도 안 쓴 어휘는 R에 안 잡힌다.
  → 채택율은 **상한 편향**(요청 어휘 중 '어차피 Suno 어휘인 것'만 세므로). 이 편향의 크기를
  L의 요청 SP 커버리지로 같이 보고한다.
- **부분문자열 매칭은 거칠다.** 굴절·동의어·부정문(`no drums`)을 못 가른다.
  → 수기 표본 점검 20건을 붙이고 오탐률을 적는다.
- **모든 값은 v3.2 파서 산출에 종속.** 파서가 바뀌면 값도 바뀐다.
